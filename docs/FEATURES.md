# 트립노선 기능 상세 (작업할 때 필요한 절만 찾아 읽기)

CLAUDE.md에는 요약만 둠. 기능을 고치거나 새로 만들 때 그 기능의 줄을 이 파일에서 찾아 읽고, 바꾸면 여기도 같이 고친다.

## 기능 (v0.24)

동작하는 것
- 9단계 전체 흐름, 상태는 브라우저 localStorage에 저장. 처음 열면 동행·날짜·담은 곳이 모두 비어 있음
- **보관함** (7단계): 항공권·숙소·입장권·교통·입국 QR·보험 예약을 날짜별로. 예약번호 복사, 티켓·QR 사진/PDF 첨부(IndexedDB 'tripnoseon-files', 큰 사진은 긴 쪽 2000px로 줄이고 PNG는 PNG 그대로), 크게 보기·보내기(Web Share)·첨부 지우기. 담은 곳 중 예약이 필요한 곳(book)·정한 숙소·항공권·Visit Japan Web 중 아직 없는 것을 제안. **이 기기에만 저장, 함께 짜기로 공유 안 함**
- **가계부·정산** (8단계, `js/ledger.js`): 한 줄 입력("라멘 1200엔", "어제 택시 2800 카드", "아빠가 디즈니 입장권 4장 39600엔", "여행 전 유심 25000원", "3그릇 980엔씩", "따로"=혼자 부담)을 읽어 금액·통화·날짜·분류·낸 사람·결제를 채우고, 쓰는 동안 '이렇게 적혀요' 미리보기와 적은 뒤 '되돌리기'. 기본값은 직접 써 본 앱들에서 가장 편했던 쪽으로: 통화는 여행지 돈(엔), 날짜는 여행 중이면 오늘·여행 전이면 1일차(항공·숙소·입장권은 '여행 전')·여행 뒤면 마지막 날. '만'으로 쓴 금액("45만")은 원화로 봄. 자세히 적기·고치기·지우기(두 번 누름), 여행 전/날짜별/여행 후 묶음, 분류별·결제별 합계, 나누는 사람(이름 고치기·더하기·함께 짜는 사람 이름 넣기)과 낸 돈·몫·'누가 누구에게 얼마'(정수로 맞춰 합이 딱 맞게). 원화 합계는 받아 온 환율 또는 직접 넣은 정산 환율. **예산**(`js/budget.js`): 여행 전체 예산(원, '200만'처럼 적어도 됨)과 원하면 분류별 예산. 엔 지출은 같은 환율로 원화로 바꿔 쓴 돈·남은 돈·%를 보여 주고, 여행 전이면 '여행 N일 동안 하루에 얼마씩', 여행 중이면 '오늘 포함 N일, 하루에 얼마씩 · 오늘 남은 돈'(하루 몫은 오늘 쓴 돈을 빼기 전 값이라 하루 동안 안 바뀜, 오늘 하루 화면에도 한 줄). 90% 넘으면·넘으면 빨간 경고 대신 주황 상자로 부드럽게. 전체 예산이 없으면 분류별 합이 전체. **엑셀로 내보내기**(`js/ledgerexport.js`): 지출 목록(날짜·일차·분류·내용·금액·통화·원화 환산·낸 사람·누구 몫·결제)과 마지막 줄 합계를 UTF-8 BOM·CRLF CSV(`tripnoseon-ledger-날짜.csv`)로. 폰은 공유 창, 안 되면·PC는 내려받기. =·+·-·@로 시작하는 글은 앞에 '를 붙여 엑셀이 수식으로 읽지 않게. **함께 짜기 여행이면 참여자 모두와 공유**(지출은 한 건씩 따로 올려 동시에 적어도 안 덮어씀, 예산은 통째로), 아니면 이 기기에만
- **안전·긴급 정보 한 장** (단계 밖, 위 '긴급' 버튼·오늘 하루 화면, `js/safety.js`): 110·119 큰 전화 버튼, 일본 관광 핫라인(한국어 24시간)·도쿄 외국어 의료 안내(한국어)·#7119·영사안전콜센터·대사관 긴급전화·영사과를 누르면 바로 거는 링크(로밍에서도 걸리게 +81). 번호는 2026-10-27 공식 누리집으로 확인했고 화면에 확인 날짜를 보여 줌(바꿀 땐 공식 출처로 다시 확인하고 `CHECKED`와 테스트도 고칠 것). 숙소 일본어 카드('この住所に行きたいです' + 숙소 이름·주소·전화, 택시 기사에게 크게 보여 주기), 아이 동반이면 만날 장소·부모 연락처·미아 카드(일본어), 보여 주는 일본어 9문장(누르면 화면 가득), 지진 때 행동, 분실(여권·지갑·전철·아이), 대사관 주소. 숙소 주소·만날 장소(`safety`)는 함께 짜기로 공유, 부모 연락처(`sphone`)는 이 기기에만. 인터넷 없이 열림
- **비 오는 날 실내 대안** (`js/rain.js`, 일정 단계 날짜마다·오늘 하루 화면): 장소마다 `indoor`(true 실내 / 'part' 반쯤 / false 실외, 시부야 스카이는 옥상이라 실외). 예보(출발 16일 안)에 비(확률 50% 이상 또는 비·눈)가 있으면 그날 상자가 저절로 열리고, 아니면 '☔ 비 오면?'으로 미리 보기. 실외·반쯤 실외 장소마다 가까운 실내 대안 3곳(그날 휴무·이미 일정에 있는 곳·아이 동반 시 어른 골목 제외, 전망대는 뒤로)을 '바꾸기' 한 번으로: 실외 장소는 빼두기, 실내 장소를 그날에. 되돌리기 있음. 하루 종일 장소(디즈니)가 비 오는 날이면 예보상 가장 맑은 다른 날로 '그날로 옮기기'(그곳이 쉬는 날은 빼고, `closedOn`). 일정 단계 머리에 담은 곳 중 실내 몇 곳인지, 날짜 머리에 예보
- **준비물 체크리스트** (7단계, `js/packing.js`): 여행지·달(겨울이면 패딩·장갑·핫팩·립밤)·이맘때 날씨(아침 기온·비 온 날 %)·동행(아이 나이별: 아이 여권, 미아 대비 연락처 카드, 10살 이상 휴대폰 로밍, 3살 이하 기저귀·유모차)·담은 곳(디즈니 앱·돗자리·저녁 방한, 팀랩 걷을 바지)에 맞춘 추천을 이유와 함께 보여 주고 한 번에 담기. 일본이면 돼지코·엔화 현금·Suica·Visit Japan Web·장바구니·쓰레기봉투. 직접 더하기(쉼표로 여러 개, 분류 자동), 누구 짐(가계부의 나누는 사람)·체크·빼기(추천에서 온 건 숨김으로 남겨 다시 추천 안 함), 전체/남은 것/공용/사람별 거르기, 진행률. **함께 짜기 여행이면 가족 모두와 공유**(한 개씩 따로 올림, 누가 챙겼는지 표시). 오늘 하루 화면(출발 전)에 진행률
- **오늘 하루** (단계 밖 화면, `js/today.js`, 위 '오늘' 버튼): 여행 중 그날 처음 열면 자동으로 뜸(`todayOpened`). 날짜 칩으로 다른 날 보기, 출발 전엔 1일차 미리 보기. 그날 날씨(예보 > 이맘때 평균), '다음 장소' 카드(큰 길찾기 버튼, 앞 장소를 다녀왔으면 그곳에서 출발)·하루 종일 장소 카드, 동선 목록(숙소 출발 → 장소마다 다녀옴 ✓·길찾기 → 숙소로 돌아가기), 그날 꺼낼 예약(보관함에서 그날 날짜 + 그날 장소에 연결된 날짜 없는 것, 예약번호 복사·QR 크게 보기), 그날 쓴 돈과 한 줄 입력(날짜를 안 쓰면 보고 있는 날). 장소마다·하루 종일 장소 카드에 '💴 여기서 쓴 돈'(v0.21): 누르면 한 줄 칸에 그 장소가 붙어 금액만 써도 됨 → 지출에 장소 id(`pl`), 내용이 비면 장소 이름, 분류를 못 정하면 장소 종류로(`ledger.js atPlace`). 가계부 목록에 📍장소. 다녀옴 표시(`tdone`)는 기기마다, 공유 안 함
- **영수증 사진** (가계부 지출마다 '🧾 영수증 사진', v0.21): 사진·PDF를 보관함 첨부 방식(IndexedDB, 사진 줄이기, 15MB)으로 붙이고 지출 아래 작은 사진, 누르면 크게 보기·보내기·지우기. 보관함 항목 kind 'receipt' + `spendId`로 저장해서 백업에 같이 들어감(보관함 목록·예약 제안·오늘 꺼낼 예약에는 안 보임, `vault.js bookings`). **이 기기에만**(함께 짜기로 공유 안 함). 지출을 지우면 영수증도 지움
- **가족 위치 (켜는 사람만)** (오늘 하루 화면, v0.22, `js/loc.js`): 함께 짜기 여행에서만. '내 위치 보여 주기' → 켜기 전에 보는 사람(참여자 이름)·언제까지(여행 마지막 날)·언제 올라가는지(앱을 열어 둔 동안만, 50m 움직이면 바로·아니면 2분마다, 20초 안엔 다시 안 올림)·얼마나 자세히(소수 넷째 자리, 약 10m)를 보여 주고 동의를 받음. 참여자 위치 목록(나 먼저, 몇 분 전, 30분 넘으면 '오래된 위치', 나와 거리, 구글 지도 링크). 서버 `trips/{여행}/locs/{uid}`(`firestore.rules`: 참여자만 읽고 자기 것만 쓰고 지움, 주인은 여행 지울 때 지움). 끄기·로그아웃·공유 끊기·여행에서 빠지기·빠지게 하기·마지막 날이 지난 뒤 처음 열 때 서버 위치를 지움. `expireAt`(마지막 날 +2일)는 넣어 두지만 Firestore TTL은 결제가 켜진 프로젝트에서만 돼서(2026-10-29 확인, Firebase는 Spark 요금제 유지) 지금은 쓰지 않음. 여행이 끝난 위치는 화면에서 빼고(`until`), 서버에서는 앱이 지움: 공유 여행을 열면 여행 주인은 끝난 위치를 모두, 다른 사람은 자기 것을 지움(`loc.js expiredLocs`, v0.22.1). 켰는지(`locOn`)는 기기마다, 백업에서 뺌. 웹앱이라 백그라운드에서는 안 올라감. 마지막 날이 지났는지는 여행지 날짜로 봄(`loc.js locToday` = `today.js tripClock(REGION.tz)`, 화면과 같음)

- **백업 · 되돌리기** (보관함 단계 맨 아래): 일정·숙소 후보·가져온 장소·보관함(첨부는 base64로 포함)을 `tripnoseon-backup-날짜.json` 하나로. 폰은 공유 창, PC는 내려받기. 라쿠텐 키는 체크할 때만 포함. 되돌리기 전 내용 요약을 보여 주고, 바꾸기 전 상태는 `tripnoseon-before-restore`에 보관해 '되돌리기 취소' 가능. 공유 여행이 연결된 백업이면 일정은 서버 최신 내용을 따름(옛 백업이 가족 일정을 덮어쓰지 않게). 다른 지역 일정의 백업이면 그 지역 데이터를 먼저 불러온 뒤 바꿈(`app.js useRegionOf`, 되돌리기 취소·참여 전 일정으로도 같음 — 안 그러면 옛 지역 동네로 그려져 숙소 동네 화면이 멈췄음, 2026-11-03 합친 뒤 점검). 남이 준 백업 파일일 수도 있어서 되돌릴 때 `__proto__` 칸은 버리고(`parseBackup`), 칸 모양을 바로잡고(`restoreState` → 일정 칸은 `cleanShared`, 단계·보관함·글자 칸·여행 번호 모양), 첨부 종류는 사진·PDF만 그대로 두고 나머지(HTML·SVG 등)는 열리지 않는 종류로(`safeFileType`). 첨부 크게 보기도 사진이 아니면 PDF만 새 창으로 엶(2026-11-03 보안 점검)

## 한계 (다음에 풀 것)

한계 (다음에 풀 것)
- 장소·동네 데이터는 직접 입력한 예시값. 이동 시간·가격대·휴무일은 대략값
- 아고다·한국 플랫폼은 개인에게 가격 API를 주지 않아(아고다·Booking은 승인된 제휴사만) 가격은 사용자가 적음. 아고다·트립닷컴은 주소로 숙소 이름 검색이 안 되고(도시 번호로 엶: 아고다 5085, 트립닷컴 228 = 도쿄), 한국 플랫폼 3곳은 날짜를 넣는 공개 주소 형식이 없어 첫 화면을 엶. 라쿠텐 API의 숙소 번호(hotelNo)는 한국어 사이트 숙소 번호(10123456…)와 체계가 달라 같은 숙소 페이지로 바로 못 감 → 한국어 사이트는 도쿄 목록(날짜·인원 채움)을 열고 이름을 복사해 찾게 함
- 라쿠텐 요금은 첫날 1박, 객실 1개, 가장 싼 플랜 기준. 숙소 한글 이름은 공식 한국어 이름이 아니라 읽는 법이라 예약 사이트 이름과 조금 다를 수 있고, 사전에 없는 영어 말은 소리대로 옮겨져 어색할 수 있음(사전은 `janame.js` LOAN에 더함). 아이 나이는 일본 학년 기준(10~12살 초등 고학년, 6~9살 저학년, 5살 이하 유아, 13살 이상 어른)으로 보냄. 라쿠텐 외 숙소 가격은 직접 넣음. 디즈니까지 시간은 숙소가 속한 동네 기준 대략값. 이름으로 위치 찾기는 지점이 많은 체인 호텔에서 거의 실패함
- 구글 테이크아웃 저장 목록 CSV에는 좌표가 없음(이름·메모·링크뿐). 이름 검색은 한국어 이름의 체인 식당 등에서 자주 실패함. 가져온 곳은 영업시간·평점이 없음
- 교통패스 계산은 직선거리 어림이라 실제 경로·환승과 다름. 낱개 표는 더 싼 도쿄 메트로 IC 운임으로만 셈(도에이·메트로↔도에이 갈아타기는 더 비싸서 실제로는 패스가 조금 더 이득일 수 있음). JR(야마노테선 등)을 타는 경우·공항 오가는 길·패스 밖 노선 요금은 안 셈. 48·72시간권은 '연속한 2·3일'로 봐서 실제(처음 탄 시각부터)와 조금 다름. 패스 밖 지역은 좌표 상자로 정해서 새 장소가 경계 근처면 틀릴 수 있음
- 이동 시간은 직선거리 어림이라 실제 노선·환승·배차와 다름(특히 JR·사철 갈아타기, 역에서 먼 곳). 일정·숙소 계산의 거리는 직선거리. 앱 안 길찾기는 없음(구글 지도로 연결). 구글 길찾기 API는 일본 대중교통 경로를 주지 않는 것으로 알고 있어 직접 만들지 않음
- 도쿄와 홍콩·선전만 지원. 다른 도시는 "준비 중" 버튼만 있음. 홍콩·선전 장소 좌표는 위키백과·OpenStreetMap 자료를 대조한 값이고(본토 지도는 GCJ-02라 구글 지도 위에서 선전이 수백 m 어긋나 보일 수 있음), 국경 통과 시간·가격대는 대략값. 홍콩 숙소 사이트 번호(아고다·트립닷컴)는 사이트 주소 기준이라 바뀔 수 있음
- 홍콩 MTR 다음 열차는 MTR역만(버스·트램·페리·경전철 없음). 브라우저에서 바로 부르는데 CORS를 배포 주소로 직접 확인하지 못했음(위 기능 줄). 역은 직선거리로 고르고 출구·걷는 길은 모름
- 국경 대기 시간은 앱 안에서 못 보여 줌(출입국관리처 자료가 브라우저 호출을 막음) — 홍콩 보안국 페이지 링크로 대신. 선전 쪽 심사 대기 없음. 넘는 날 짐작은 동선의 국경 구간·숙소 도시·이동에 적은 말로만 함
